## 什么是 Wan 3.0 Video？

**Wan 3.0 Video** 页面整理了带有来源链接的公开演示与社区工作流。本集合区分可观察的能力证据和编辑重构：每个案例都保留创作者、原始帖子、可播放结果与模型表述；重构提示词会明确标注，不会伪装成逐字原文。可用性、限制和功能可能变化，投入制作前请确认当前访问条件。

编写实用提示词时，把每次请求当作镜头简报，而不是情绪板。写清可见动作、镜头行为、节拍时间、声音方案、参考素材，以及必须保持稳定的内容。

- **从文本或画面开始** - 根据文字场景生成，或让已经承载构图的图像动起来
- **描述可观察的运动** - 写清调度、动量、物体交互，以及每个动作造成的物理后果
- **写节拍，不写梗概** - 时序重要时，使用时间码或简短动作序列
- **让声音与场景一起生成** - 故事需要音频时加入对白、环境声、音乐或音效
- **编辑现有素材** - 重塑片段风格、改变场景条件，或添加、移除、替换可见元素
- **明确保护连续性** - 指出脸部、产品结构、布局、服装或背景中不能漂移的部分

**当前参考：** [Wan 3.0 workflow on ImagineVid](https://imaginevid.io/zh/text-to-video)

### 把提示词变成镜头模板

可复用的视频提示词将场景变量与导演逻辑分开。替换主体、环境、台词或产品，同时保留经过验证的镜头路径、节拍结构、声音方案和连续性规则。

**模板模式：**
```
[DURATION + ASPECT RATIO]。[SUBJECT] 在 [SETTING] 中执行 [VISIBLE ACTION]。Camera: [FRAMING + MOVE]。Beats: [TIMED ACTIONS]。Audio: [DIALOGUE + FOLEY + AMBIENCE]。Preserve: [IDENTITY / PRODUCT / LAYOUT]。Avoid: [FAILURE MODES]。
```

从一个动作和一个镜头想法开始。只有在解决可见制作需求时才加入时间、音频和保留约束；然后每次生成只改变一个变量。

### #1: 雨幕竞技场中的清晰拳击编排

![Language-EN](https://img.shields.io/badge/Language-EN-blue)
![Featured](https://img.shields.io/badge/Featured-gold-gold)
![Reference](https://img.shields.io/badge/Reference-Image%20Needed-orange)

#### 工作流为何重要

一份 17 秒动作简报：分开两位选手、编排每次攻防，并用雨水、水洼、镜头和连续性约束保持决斗清楚可读。

#### 本地化提示词

```
制作一段 17 秒、16:9、电影感 3D 写实拳击视频：两位成年女性选手在夜晚一座破败的圆形石头竞技场内交手。全程保持面孔、体型、服装和站位一致。只使用拳击、格挡、拍挡、闪避和步法。用低机位大全景开场，交锋时切换到侧向跟拍，加入一次短暂的闪避慢动作，最后在干净的上勾拳后以受控的半环绕结束。轻雨、反光水洼、冷月光、暖火把、真实汗水和水滴。不要对白、字幕、音乐、武器、超能力、解剖错误、重复人物或水印。
```

Start with a low wide shot, move into lateral tracking during the exchange, add one brief slow-motion dodge, then finish on a controlled half-orbit after a clean uppercut. No dialogue, captions, music, weapons, powers, anatomy errors, duplicate characters, or watermark.

### #2: 固定屏幕方向的七镜头长枪决斗

![Language-EN](https://img.shields.io/badge/Language-EN-blue)
![Featured](https://img.shields.io/badge/Featured-gold-gold)

#### 工作流为何重要

一份七镜头赛璐璐动画源提示词，固定屏幕空间、动作向量、能量配色、冲击定格和剪辑之间的连续性。

#### 本地化提示词

```
制作一段 15 秒、16:9、手绘 2D 赛璐璐动画战斗，共七个镜头。小个子长枪战士从画面左侧开始，巨大的格斗家从右侧开始，整段保持同一摄影机轴线。长枪战士使用青色能量，格斗家使用炽橙色能量。依次表现蓄势、投掷石板、跃过碎石、空中碎片阶梯、短暂慢动作的反手击、眼睛特写，以及带半拍静音和冲击定格的最后一记长枪突刺。保持角色设计、面孔、伤口、竞技场损伤、沉重碎石物理和严格的七镜头数量。不要额外镜头、文字、字幕、水印或身体融合。
```

```
Create a 15-second, 16:9 seven-shot 2D hand-drawn cel-animated fight. A small spear fighter starts screen-left and a massive brawler starts screen-right; keep that south-side camera axis throughout. Use cyan energy for the spear fighter and ember-orange energy for the brawler. ### #3: 只有一个视觉揭示的电视剧开场
```

![Language-EN](https://img.shields.io/badge/Language-EN-blue)
![Featured](https://img.shields.io/badge/Featured-gold-gold)

#### 工作流为何重要

对 Wan 3.0 电视剧式开场展示中的镜头逻辑进行透明重构：先建立地点，再揭示人物，最后落在有动机的节拍上。

#### 本地化提示词

```
制作一段 30 秒、16:9 的电视剧开场，所有内容处于同一个连贯的视觉世界。用黎明时安静的大全景开场，随后推向一个走在雨湿城市街道上的人物。只在叙事节拍变化时剪辑：倒影揭示第二个人物，镜头跟随主角走到遮雨棚下，缓慢推进在他注意到手中物件的瞬间结束。保持服装、天气、建筑和屏幕方向一致。使用克制的自然色、脚步声、雨打金属声、远处交通声，以及揭示时低沉的音乐上扬。不要字幕、标志或任意重置场景。
```

<details>
<summary>原始来源提示词</summary>

```
Create a 30-second, 16:9 television-drama opening in one coherent visual world. Begin with a quiet wide establishing shot at dawn, then track toward a lone character moving through a rain-wet urban street.
```
