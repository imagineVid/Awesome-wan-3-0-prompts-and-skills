## Wan 3.0 Video란?

**Wan 3.0 Video**를 출처가 연결된 공개 데모와 커뮤니티 워크플로를 통해 정리합니다. 이 컬렉션은 관찰 가능한 기능 증거와 편집자가 재구성한 내용을 구분합니다. 각 사례에는 제작자, 원본 게시물, 재생 가능한 결과, 모델 표기를 남기며, 재구성한 프롬프트는 원문인 것처럼 제시하지 않고 명확히 표시합니다. 이용 가능 여부와 기능은 바뀔 수 있으므로 제작 전에 현재 접근 조건을 확인하세요.

실용적인 프롬프트는 무드보드가 아니라 샷 브리프로 작성하세요. 보이는 동작, 카메라 움직임, 비트 타이밍, 사운드 계획, 참조 입력과 유지해야 할 요소를 구체적으로 적습니다.

- **텍스트나 프레임에서 시작** - 글로 쓴 장면에서 생성하거나 이미 구도를 담고 있는 이미지에 움직임을 부여하세요
- **관찰 가능한 움직임을 연출** - 각 동작의 블로킹, 운동량, 객체 간 상호작용, 물리적 결과를 설명하세요
- **시놉시스가 아니라 비트를 작성** - 타이밍과 공개 순서가 중요할 때 타임스탬프나 짧은 동작 시퀀스를 사용하세요
- **장면과 함께 사운드를 생성** - 오디오가 스토리텔링의 일부라면 대사, 분위기음, 음악 또는 효과음을 포함하세요
- **기존 영상을 편집** - 클립의 스타일을 바꾸고, 장면 조건을 변경하거나 보이는 요소를 추가, 제거, 교체하세요
- **연속성을 명시적으로 보호** - 변형되어서는 안 되는 얼굴, 제품의 형태, 레이아웃, 의상 또는 배경을 밝혀 두세요

**현재 참고 자료:** [Wan 3.0 workflow on ImagineVid](https://imaginevid.io/ko/text-to-video)

### 프롬프트를 샷 템플릿으로 바꾸기

재사용 가능한 비디오 프롬프트는 장면 변수와 연출 논리를 분리합니다. 검증된 카메라 경로, 비트 구조, 사운드 계획, 연속성 규칙은 유지하면서 주제, 배경, 대사 또는 제품을 바꾸세요.

**템플릿 패턴:**
```
[DURATION + ASPECT RATIO]. [SUBJECT]가 [SETTING]에서 [VISIBLE ACTION]을 수행한다. Camera: [FRAMING + MOVE]. Beats: [TIMED ACTIONS]. Audio: [DIALOGUE + FOLEY + AMBIENCE]. Preserve: [IDENTITY / PRODUCT / LAYOUT]. Avoid: [FAILURE MODES].
```

동작 하나와 카메라 아이디어 하나로 시작하세요. 눈에 보이는 제작 요구를 해결할 때만 타이밍, 오디오, 보존 제약을 추가하고, 생성 간에는 한 번에 변수 하나만 바꾸세요.

##### 현지화 프롬프트

```
30초, 16:9 시네마틱 환경 reveal을 만드세요. 블루 아워에 인물이 높은 창을 여는 조용한 실내에서 시작합니다. 느린 핸드헬드 푸시로 동작을 따라가고, 구름과 먼 불빛, 가까운 천에 보이는 바람이 있는 넓은 해안 풍경으로 나가세요. 세계가 열리는 동안 인물과 건축을 일관되게 유지하세요. 실내 공간음에서 바람, 새, 파도, 절제된 오케스트라 상승으로 전환합니다. 마지막 와이드 숏은 몇 초 동안 유지하세요. 공간 연속성, 물리적 빛, 읽기 쉬운 카메라 경로를 우선하세요. 텍스트, 자막, 로고, 임의의 기술 라벨은 금지합니다.
```
