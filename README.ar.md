## ما هو Wan 3.0 Video؟

يُوثّق **Wan 3.0 Video** هنا عبر عروض عامة مرتبطة بمصادرها وسير عمل من المجتمع. تميّز المجموعة بين أدلة القدرات القابلة للملاحظة وإعادة البناء التحريرية: يحافظ كل مثال على اسم المبدع والمنشور الأصلي والنتيجة القابلة للتشغيل وذكر النموذج، بينما تُوسم المطالبات المعاد بناؤها بوضوح ولا تُقدَّم كنصوص حرفية. قد تتغير الإتاحة والحدود والميزات، لذلك تحقّق من الوصول الحالي قبل الاستخدام في الإنتاج.

لصياغة مطالبة عملية، تعامل مع كل طلب بوصفه موجز لقطة لا لوحة مزاجية. حدّد الفعل المرئي وسلوك الكاميرا وتوقيت الإيقاع وخطة الصوت والمواد المرجعية وكل ما يجب أن يبقى ثابتًا.

- **ابدأ من نص أو إطار** - ولّد من مشهد مكتوب أو حرّك صورة تحمل التكوين أصلًا
- **وجّه الحركة القابلة للملاحظة** - صف التوزيع، والزخم، وتفاعل العناصر، والنتيجة الفيزيائية لكل فعل
- **اكتب الإيقاعات لا الملخص** - استخدم الرموز الزمنية أو تسلسلًا قصيرًا للأفعال عندما يهم التوقيت والكشف
- **ولّد الصوت مع المشهد** - أضف الحوار أو الأجواء أو الموسيقى أو المؤثرات عندما يكون الصوت جزءًا من السرد
- **حرّر اللقطات الموجودة** - أعد تصميم أسلوب مقطع أو غيّر ظروف المشهد أو أضف عناصر مرئية أو أزلها أو استبدلها
- **احمِ الاستمرارية صراحةً** - حدّد الوجه أو هندسة المنتج أو التخطيط أو الملابس أو الخلفية التي يجب ألا تنحرف

### حوّل المطالبة إلى قالب لقطة

تفصل مطالبات الفيديو القابلة لإعادة الاستخدام متغيرات المشهد عن منطق الإخراج. استبدل الموضوع أو المكان أو الجملة المنطوقة أو المنتج مع الحفاظ على مسار الكاميرا وبنية الإيقاع وخطة الصوت وقواعد الاستمرارية المختبرة.

**نمط القالب:**
```
[DURATION + ASPECT RATIO]. ينفذ [SUBJECT] [VISIBLE ACTION] في [SETTING]. الكاميرا: [FRAMING + MOVE]. الإيقاعات: [TIMED ACTIONS]. الصوت: [DIALOGUE + FOLEY + AMBIENCE]. حافظ على: [IDENTITY / PRODUCT / LAYOUT]. تجنب: [FAILURE MODES].
```

ابدأ بفعل واحد وفكرة كاميرا واحدة. أضف قيود التوقيت والصوت والحفاظ فقط عندما تحل حاجة إنتاجية مرئية، ثم غيّر متغيرًا واحدًا في كل مرة بين التوليدات.

#### أهمية سير العمل

موجز حركة مدته 17 ثانية يفصل بين مقاتلتين وينظم كل تبادل، ويستخدم المطر والبرك والكاميرا والاستمرارية للحفاظ على وضوح المبارزة.

#### المطالبة المترجمة

```
أنشئ تسلسل ملاكمة سينمائيًا مدته 17 ثانية بنسبة 16:9 وبواقعية ثلاثية الأبعاد، مع مقاتلتين بالغتين داخل حلبة حجرية دائرية متهدمة ليلًا. حافظ على ثبات الوجه والجسد والملابس والمواقع. استخدم اللكمات والصدّات والمراوغات وحركة القدمين فقط. ابدأ بلقطة واسعة منخفضة، وانتقل إلى تتبع جانبي أثناء التبادل، وأضف مراوغة قصيرة بالحركة البطيئة، ثم اختم بنصف دوران مضبوط بعد ضربة علوية واضحة. مطر خفيف، برك عاكسة، ضوء قمر بارد، مشاعل دافئة، وعرق وقطرات واقعية. بلا حوار أو ترجمة أو موسيقى أو أسلحة أو قوى أو أخطاء تشريحية أو شخصيات مكررة أو علامة مائية.
```

